# Good Girl Study Plan

這是一個給女孩、家人共同使用的升學支援計畫。

目標是幫助女孩在台灣從小學、國中、高中到大學的求學過程中：

- 了解目前可選擇的升學路徑
- 在正確的時間完成報名、考試、選填志願與資料準備
- 建立適合自己的學習習慣、興趣探索與能力補強計畫
- 保留成績、作品、活動、證照與重要文件
- 在重要升學決策時，有清楚的資訊、選項與討論紀錄

## 這個專案給誰使用

- 女孩：了解自己現在該做什麼、未來有哪些選擇
- 主要照顧者：知道每個月要留意什麼、保存什麼文件、何時需要聯絡遠端家人
- 遠端協助家人：掌握進度、提供升學資訊、協助做重要決策

## 使用原則

1. 不需要一次讀完所有內容。
2. 每個月先看「每月固定任務」。
3. 遇到升學名詞不清楚時，先查 `03-study-roadmap/glossary.md`。
4. 遇到選校、選班、選課或報名時，先看 `06-decisions/`。
5. 所有成績單、獎狀、證照、作品照片與活動紀錄，都放入 `05-records/`。
6. 不確定的事情，先記錄下來，再向學校導師、輔導室或官方網站確認。

## 每月固定任務

### 每個月的第一週

- 檢查女孩的作業、考試與學習狀況
- 更新 `04-action-plans/` 的本月目標
- 檢查是否有學校通知、報名、繳費或活動截止日

### 每個月的中旬

- 和女孩聊一次：
  - 最近喜歡什麼？
  - 哪一科覺得難？
  - 有沒有想參加的活動？
  - 有沒有讓她感到壓力的事情？

### 每個月的最後一週

- 將重要成果、證書、照片與老師回饋放入 `05-records/`
- 更新 `02-child-profile/child-profile.md`
- 檢查下一個月是否有升學相關的重要日期

## 給主要照顧者的提醒

- 不需要完全懂所有升學制度。
- 最重要的是幫女孩穩定上學、按時完成作業、參加必要活動，並保留證明文件。
- 學校發的通知單、家長日資料、競賽與活動資訊，請拍照或掃描後放入 `05-records/`。
- 若學校提到「免試入學」「志願選填」「學習歷程」「特殊選才」等名詞，請先記錄日期與要求，再與遠端家人討論。

## 給遠端協助者的提醒

- 每月至少檢查一次女孩的學習與升學進度。
- 每學期至少與女孩、主要照顧者或導師確認一次現況。
- 在重要升學節點前 3 到 6 個月，提前確認官方時程與所需文件。
- 不要只看分數；也要關注興趣、心理健康、人際關係、生活能力與探索機會。

## 個人資料與版控

- `02-child-profile/child-profile.md` 是家庭的本機個人檔案，不會納入版控。可從 [個人檔案範本](02-child-profile/child-profile.template.md) 複製後，在本機填寫。
- `05-records/` 與 `06-decisions/` 可能包含個人或家庭資料，已排除於版控。
- 分享或提交前，請確認內容不含可識別個人身分的資料、學校資訊、成績或私人文件。

## 資料夾規劃

```text
Good-Girl-Study-Plan/
├── README.md
├── 01-family-guide/
├── 02-child-profile/
├── 03-study-roadmap/
├── 04-action-plans/
├── 05-records/
└── 06-decisions/
```

| 資料夾 | 用途 |
|---|---|
| `01-family-guide/` | 給主要照顧者的每月任務、學校聯絡與重要日期紀錄 |
| `02-child-profile/` | 女孩的現況、興趣、強弱項、學習狀況與家庭條件 |
| `03-study-roadmap/` | 台灣升學路徑、時間軸、名詞解釋與各階段重點 |
| `04-action-plans/` | 每週、每月、每學期的具體行動清單 |
| `05-records/` | 成績、作品、證照、活動、競賽與重要文件 |
| `06-decisions/` | 選校、選班、選課、報名與志願決策紀錄 |
