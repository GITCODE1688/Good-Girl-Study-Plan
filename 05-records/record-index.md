# 紀錄索引

這份文件用來索引女孩的重要學習與成長紀錄。

請將紙本文件掃描或拍照，將電子檔案放入 `05-records/` 的適當子資料夾，並在本文件登錄基本資訊。不要把密碼、身分證字號、金融資訊或其他敏感個資寫進這份文件。

## 使用原則

1. 每學期至少整理一次。
2. 重要文件應同時保留原始檔與可讀取的備份。
3. 檔案名稱應包含日期與內容，例如：`2026-11-12_數學競賽_證書.pdf`。
4. 不確定是否有用的文件，先保存，之後再判斷。
5. 每筆紀錄都應註明日期、來源與意義。

## 建議的子資料夾

```text
05-records/
├── academic/
├── activities/
├── competitions/
├── certificates/
├── projects/
├── feedback/
└── school-notices/
```

| 子資料夾 | 放什麼 |
|---|---|
| `academic/` | 成績單、學習單、考卷、作業與學習紀錄 |
| `activities/` | 社團、志工、營隊、展覽與校外活動 |
| `competitions/` | 競賽報名資料、作品、成績與獎狀 |
| `certificates/` | 語言檢定、資訊證照、技術證照與其他證書 |
| `projects/` | 專題、程式、設計、寫作、影片與研究作品 |
| `feedback/` | 老師回饋、輔導紀錄、家長日資料與諮詢紀錄 |
| `school-notices/` | 學校通知、家長日資料、報名資訊與重要日程 |
