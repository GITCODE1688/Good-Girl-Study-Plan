# 決策紀錄

這份文件用來記錄女孩升學路上的重要決策。

每次做出選校、選班、選課、報名、參加活動、選擇社團或決定升學方向時，都應記錄當時的選項、理由、風險與後續行動。這不是為了追究對錯，而是為了讓未來能看懂當時為什麼這樣決定，並在情況改變時及時調整。

## 使用原則

1. 重大決策前，先列出至少兩個可行選項。
2. 決策前，確認女孩本人的想法與意願。
3. 決策後，記錄決定、原因、風險與下一步。
4. 若情況改變，不要害怕修改決定；應記錄修改原因。
5. 涉及報名、繳費、簽約或提交文件前，務必核對官方最新簡章與期限。

## 決策檢查清單

在做出重要決定前，請確認：

- [ ] 女孩已表達自己的想法
- [ ] 已了解所有可行選項
- [ ] 已確認報名、考試或繳費期限
- [ ] 已確認費用與家庭能否負擔
- [ ] 已確認交通、住宿或照顧安排
- [ ] 已確認學校或科系的入學條件
- [ ] 已確認若未錄取，是否有備案
- [ ] 已記錄決策原因與檢視日期
